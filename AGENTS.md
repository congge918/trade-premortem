# Project instructions

- Keep the demo dependency-free and runnable with Node.js 20+.
- Never put model keys, exchange credentials, wallet code, or order execution in the browser or repository.
- Only call Bitget endpoints documented with no permission requirement; replay data must be visibly labelled.
- Deterministic code owns calculations and verdict gates. A language model may explain evidence but cannot override a gate.
- Run `npm test` after changing the stress engine, evidence model, or audit logic.
